# Project guidelines

## Screen implementation rules

- Do not add a "Clipboard" (paste-from-clipboard) button to any tool screen, even if a reference screenshot shows one.
- Do not add a "Settings" / gear button to any tool screen, even if a reference screenshot shows one. If a screen needs options, expose them with a visible control (e.g. a dropdown) instead.
- Do not add CSS or JavaScript for these omitted controls (for example, `navigator.clipboard.readText()` handlers).
